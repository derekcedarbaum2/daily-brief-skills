# Daily meals and supplement preparation

Ask about meals and supplement preparation in every planning interview.
Check the target day's breakfast, lunch, and dinner for the user and applicable household members.
Use confirmed recurring meals as defaults and ask what changes.
If the rundown already covers the meals, record the answer without asking again.
Ask what the user or another household member needs to prepare before the target day: shopping, thawing, cooking, packing, or setting items aside.
Record the owner, preparation window, duration estimate, and completion deadline when known.
Put preparation before its deadline and include it in the capacity calculation.
Connect missing ingredients to an upcoming grocery trip.
For weekend-to-workweek planning, include the next working day's lunches and other preparation with a lead time.
Keep weekly menu design optional; the daily check does not require a full meal-planning project.

Ask which existing supplements need to be set out or packed for the user and family.
Use only the regimen and instructions the user provides or confirms.
Do not invent products, doses, timing, or supplements for children.
Record no preparation needed when the user says none.
If the regimen is unknown, ask what preparation is needed rather than suggesting a regimen.
Keep medical choices separate from preparation logistics.

Ask the daily checks even when earlier baseline meal setup was deferred.
Honor a refusal for the current interview, record it, and continue the brief with the gap labeled.
Ask again at the next planning interview unless the user explicitly changes the daily requirement.
Do not repeat the checks when resuming an interview that already answered them.
Print only actionable meal and supplement preparation, confirmed meal plans, and consequential gaps.
Do not add empty food or supplement sections to the report.
